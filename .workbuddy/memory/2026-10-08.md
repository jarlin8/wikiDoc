# 2026-10-08 工作日志

## wencai.py 在 GitHub Actions 报错诊断（'NoneType' object has no attribute 'get'）

**触发**：用户提供 Actions 日志包 `logs_102380432115.zip`（jarlin8/wikiDoc 的 wencai.yml，ubuntu-latest + Python 3.12 + pywencai 0.13.1）。

**根因（实测证据，非推断）**：
1. 直接原因：pywencai `get()` 里 `params = get_robot_data(...)` 返回 None → `params.get('data')` 崩溃。`while_do` 会把 10 次重试的真实异常全部吞掉，所以日志里看不到原始错误。
2. 真实原因（本机复刻请求链路实测）：无 cookie 时问财 `get-robot-data` 接口返回 **403 Forbidden（openresty WAF，HTML 非 JSON）** → `convert()` JSON 解析失败。加浏览器全套请求头 / 换 https / 空 cookie 均 403，WAF 要的是**真实登录 cookie**。
3. 与 pywencai README 一致：「由于问财登录策略调整，目前必填 cookie 参数才能使用」。
4. 社区佐证：issue #85（2026-08，更新 cookie 仍 403 → 云服务器/机房 IP 被封）；#79（缺 nodejs 导致同类报错，装 node 好了）；#66（本地正常、阿里云不行 → IP 问题）。

**关于「装 jsdom 就好」的评论（已证伪）**：
- pywencai 0.13.1 的 `package.json` 确实声明 jsdom 依赖，但 jsdom 已被打包进 5.1MB 的 `hexin-v.bundle.js`。
- 实测本机直接 `node hexin-v.bundle.js` 成功输出 60 位 hexin-v 令牌，无需 npm install。
- 该评论适用于旧版（execjs 跑未打包 hexin-v.js）或「缺 Node 运行时」场景（如 #79），不适用于本案。

**修复（已落盘）**：
- `wencai.py`：cookie 改从环境变量 `WENCAI_COOKIE` 读取（缺失秒退并提示抓取方法）；`pywencai.get(..., cookie=cookie, log=True)`；try/except AttributeError 捕获 pywencai 内部崩溃并给出中文根因提示（cookie 失效 / IP 被封）。顺带删除了从未使用的 `hexin_v_file` 死代码。
- `.github/workflows/wencai.yml`：Run 步骤注入 `WENCAI_COOKIE: ${{ secrets.WENCAI_COOKIE }}`。
- 两条防线均已本地验证（无 cookie / 假 cookie 路径，退出码均为 1，报错可读）。

**待用户完成**：
1. 浏览器登录 iwencai.com → F12 → Network → 任一请求 → 复制整段 Cookie。
2. GitHub 仓库 Settings → Secrets and variables → Actions → 新建 secret `WENCAI_COOKIE`。
3. 提交推送 wencai.py + wencai.yml，重跑 workflow。
4. ⚠️ 风险提示：GitHub Actions 是境外机房 IP，即使 cookie 有效仍可能被 WAF 拦（见 #85，国内云服务器都被封）。兜底方案是本地跑（国内住宅 IP + cookie，如 #66 案例）。cookie 有效期有限，失效后需重新抓取。
