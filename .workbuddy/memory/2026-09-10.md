**规则**：
1. **在本仓库（以及任何 Windows + Git Bash 环境）禁用 `git rm -r`**，改用普通 `rm` / `rm -rf`。

### 脚本踩坑
`splitFrontMatter` 初版用 `rest.match(/^---[ \t]*\r?\n/)` 找结束分隔符 → **425 篇全部误判为无前置元数据**。
原因：`^` 未加 `m` 标志时只匹配字符串起始位置，而结束分隔符位于内容之后。
正确写法：`rest.match(/\n---[ \t]*(\r?\n|$)/)`。
