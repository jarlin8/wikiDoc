## ⚠️ 环境备忘（本轮再次踩到）
- **Bash/Write/Edit 曾在某一轮次不可用**（模式显示 Agent 但工具未挂载）→ 遇到时不要假报完成，直接说明并请用户重发消息
- Bash 每条命令都需显式 export 完整 PATH（含 Git cmd、PortableGit usr/bin、node），**不要依赖 `$PATH`**
- 无 `yarn` 时的构建命令：`node node_modules/@docusaurus/core/bin/docusaurus.mjs build`
- `/tmp` 在不同 shell 下映射不同目录 → 日志可能"找不到"，应直接检查 `build/` 产物
- Docusaurus 压缩 HTML 会**去掉属性引号**（`href=/xxx`），写校验正则时不能假定有引号
