## 一、先搞清楚：选择账户本质是在选“收费方式”

不要被账户名称迷惑。Exness 的账户实质上分两大类〔官方〕：

| 大类 | 收费模式 | 代表账户 |
|---|---|---|
| **标准账户** | **免佣金**，成本全部体现在点差里 | Standard、Standard Cent |
| **专业账户** | **点差极低 + 按手数收佣金** | Raw Spread、Zero、Pro |

**这两种模式的差别，才是决定你交易成本的核心。**

## 二、两种模式的成本结构差异

| | 标准账户 | 专业账户 |
|---|---|---|
| 点差 | 较宽（含经纪商加价） | 极窄，接近银行间报价 |
| 佣金 | 无 | 按每手收取 |
| 最低入金 | 极低〔第三方〕 | 明显更高〔第三方〕 |
| 适合 | 低频、小资金、新手 | 高频、剥头皮、程序化、大资金 |

**关键判断公式：**

```
标准账户总成本 ≈ 点差 × 交易手数 × 点值
专业账户总成本 ≈ (更小的点差 × 手数 × 点值) + (佣金 × 手数)
```

**分界点在于你的交易频率。** 交易越频繁，专业账户的低点差优势越能覆盖佣金；反之，低频交易者在标准账户上更划算。

## 三、选账户时真正该看的三个参数

第三方评测里常见的点差数字（如“0.0 点起”“0.2 点起”）参考价值有限，因为：

1. 点差是**浮动的**，受行情、时段、新闻事件影响
2. 宣传数字通常取的是**最低值**，不是平均值
3. 不同来源口径不一致

真正应该核对的是：**平均点差**（而非最低点差）、**每手佣金**、以及**爆仓水平与保证金要求**。

Exness 官方公布的**爆仓水平为 0%**（保证金比例降到 0% 才强平），并提供**负余额保护**〔官方〕——这两条对所有账户类型都适用，是相对优势。

## 四、逐个账户看：各自适合谁

### 标准账户（Standard）

免佣金、成本全在点差里。适合新手与低频交易者，也是门槛最低的一档。

站内详情：[[exness-trader/标准账户|标准账户]]、[[exness-trader/标准账户上可以交易哪些品种|标准账户上可以交易哪些品种]]

### 先锋账户

点差可低至 0.1 点，支持最低 0.01 手，订单数量不限。适合日内交易与自动交易。

站内详情：[[exness-trader/先锋账户|先锋账户]]

### 美分账户（Standard Cent）

以美分为计价单位，最小交易手数相应缩小，适合极小资金测试策略。但要注意：**并非所有地区都开放**，且点差通常比普通标准账户更宽。

站内详情：[[exness-trader/美分账户|美分账户]]

### 零点账户 / 裸点账户（专业账户）

两者都属于专业账户，差异集中在“点差有多窄”与“佣金多少”的权衡上——有的主打零佣金但点差略宽，有的主打零点差但佣金较高。**具体参数请以官方对比页为准**〔官方〕。

站内详情：[[exness-trader/零点账户|零点账户]]、[[exness-trader/裸点账户|裸点账户]]

## 五、选完之后还会遇到的两件事

**账户后缀**：Exness 的账户类型与货币会体现在交易品种后缀上，选错会导致下单失败。详见 [[exness-trader/关于账户类型后缀|关于账户类型后缀]]。

**隔夜利息**：不同账户对隔夜利息的收取规则不同，部分账户与地区可申请免息。详见 [[exness-trader/隔夜利息|隔夜利息]] 与 [[exness-trader/哪些账户可以免隔夜利息|哪些账户可以免隔夜利息]]。

## 六、选择建议（按人群）

| 你的情况 | 建议 |
|---|---|
| 完全新手、资金小、低频 | [标准账户](/exness-trader/标准账户) + [模拟账户](/exness-trader/如何开立模拟账户) 先练手 |
| 每周交易数次、手动 | 标准账户通常够用，算一下佣金是否划算再决定 |
| 日内高频、剥头皮 | 专业账户（[零点账户](/exness-trader/零点账户) / [裸点账户](/exness-trader/裸点账户)），成本优势明显 |
| 跑 EA、程序化 | 专业账户 + [Exness VPS](/exness-trader/exness-vps-使用须知) |
| 极小额测试策略 | [美分账户](/exness-trader/美分账户)（若所在地区开放） |
| 拿不准选哪个 | 先看 [我应该选择哪种账户](/exness-trader/我应该选择哪种账户) |

## 七、必须提醒的两点

1. **账户类型不是风险控制手段。** 真正决定盈亏的是仓位与杠杆使用，换账户类型不会降低风险。高杠杆（含“无限杠杆”）在部分账户与地区开放〔第三方〕，小额反向波动即可清零账户，不建议新手使用——延伸阅读：[[exness-trader/如何获得无限杠杆|如何获得无限杠杆]]。
2. **本站既有账户文档描述的是较早的账户体系**〔站内〕，可能与当前官方账户列表不一致。判断实际参数请以官方为准。
