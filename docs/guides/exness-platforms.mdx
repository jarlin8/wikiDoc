## 一、Exness 提供哪几类交易平台

Exness 的平台体系大致分四层〔官方〕：

| 层级 | 平台 | 定位 |
|---|---|---|
| **第三方桌面/移动终端** | MetaTrader 4、MetaTrader 5 | 功能最全，支持 EA 与自定义指标 |
| **网页交易终端** | Web Terminal（MT4/MT5 网页版）、Exness Terminal | 免安装，跨设备 |
| **自有移动应用** | Exness Trade App | 交易 + 账户管理一体化 |
| **辅助服务** | Exness VPS、社交交易（Copy Trading） | 无人值守运行 EA / 跟单 |

## 二、MT4 还是 MT5

这是最常见的选择题。核心差异：

| 维度 | MT4 | MT5 |
|---|---|---|
| 时间框架 | 9 种 | 21 种 |
| 挂单类型 | 4 种 | 6 种 |
| 技术指标 | 30 个内置 | 38 个内置 |
| 自定义指标 / EA 语言 | MQL4 | MQL5 |
| 市场深度（DOM） | 无 | 有 |
| 经济日历 | 无 | 内置 |
| 策略测试 | 单线程 | 支持多线程、多品种回测 |
| 可交易品种范围 | 以 Forex / CFD 为主 | 更广，原生支持交易所品种 |

**怎么选：**

- **已有 MQL4 EA 或依赖老的跟单社区** → 继续用 MT4
- **需要多品种回测、更快策略测试、更多时间框架** → 用 MT5
- **两者都能用 Exness 账户**，不需要二选一——可以同时安装

本站既有文档《[MetaTrader：详解对比 MT4 和 MT5](/exness-trader/metatrader-详解-对比-mt4-和-mt5)》有更详细的逐项对比〔站内〕。

## 三、网页终端与桌面端的取舍

| | 桌面终端（下载安装） | 网页终端（浏览器） |
|---|---|---|
| 安装 | 需要 | 免安装 |
| 性能与稳定性 | 更好 | 依赖网络与浏览器 |
| EA / 自定义指标 | ✅ 支持 | ❌ 通常不支持 |
| 跨设备 | 需各自安装 | 任意浏览器即用 |
| 适合场景 | 日常主力、跑 EA | 临时查看、换电脑、受限设备 |

**建议**：以桌面端为主力，网页终端作为应急或轻量查看的补充。

## 四、移动端

Exness 提供两类移动端选择：

- **Exness Trade App**：官方自有应用，交易与账户管理（出入金、验证、报表）合一
- **MT4 / MT5 手机版**：Android 与 iOS 均有，功能比桌面端精简，但支持基本下单与图表

**注意**：手机端通常不支持 EA，且触屏下单容易误操作，重要订单建议在桌面端确认。

## 五、VPS 是什么、什么时候需要

**VPS（虚拟专用服务器）** 是一台常年在线、低延迟的远程服务器。用途是：**让 EA 在没有你本地电脑开机的情况下持续运行**，同时减少因本地网络抖动导致的执行偏差。

**只有这些情况才值得上 VPS：**
- 你在跑**无人值守的 EA 策略**
- 你的策略对**执行延迟敏感**（剥头皮、高频）
- 你的本地网络或电脑不稳定

**如果只是手动交易，VPS 基本用不上。**

Exness 对达到一定交易量的客户提供 VPS 服务，具体资格条件以官方为准〔官方〕。本站既有文档见《[Exness VPS 使用须知](/exness-trader/exness-vps-使用须知)》〔站内〕。

## 六、社交交易（跟单）

Exness 提供 Copy Trading：可以关注其他策略提供者并按比例复制其交易。

**使用前必须明确的几件事：**
- 跟单**不降低风险**，只是把决策权交给别人
- 需要关注提供者的**历史回撤**，而不只是收益率
- 你有权随时停止跟单，但**已开仓位未必自动平掉**
- 跟单产生的盈亏与费用由你自己承担

## 七、选择建议（按人群）

| 你的情况 | 建议组合 |
|---|---|
| 纯新手，先熟悉界面 | Exness Trade App（或 MT5 手机版）+ 模拟账户 |
| 手动日内交易 | MT5 桌面版为主，网页终端应急 |
| 已有 MQL4 EA | MT4 桌面版 + VPS |
| 做多品种策略回测 | MT5 桌面版 |
| 想跟单、没时间盯盘 | Social Trading + Exness Trade App |
